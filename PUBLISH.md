# Публикация на GitHub

Создайте репозиторий и запушьте код (нужен ваш `gh` с правами на создание репозиториев):

```bash
cd standalone-task-tracker
gh repo create mvdamage/android-task-tracker --public --description "Android: трекер задач" --source . --remote origin --push
```

APK: `releases/task-tracker-debug.apk`
Репозиторий: https://github.com/mvdamage/android-task-tracker
