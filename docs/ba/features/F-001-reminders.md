# F-001: Напоминания о задачах

- Статус: draft
- Приоритет: Must
- Эпик: Напоминания
- Связанное ТЗ: —

## User story

Как личный планировщик (P1), я хочу получить уведомление о задаче в назначенный срок, чтобы не пропустить дело, даже когда приложение закрыто.

## Контекст / проблема

У конкурентов (Todoist Pro, TickTick, MS To Do) напоминания — базовое ожидание. В Task Tracker есть дата/время, но нет push/уведомлений → сроки не «работают» как триггер.

## Acceptance criteria

1. Given задача с датой и временем (точкой или началом интервала), When наступает это время и разрешены уведомления, Then система показывает уведомление с названием задачи.
2. Given задача только с датой (без времени), When наступает время напоминания по умолчанию (см. бизнес-правила), Then приходит уведомление.
3. Given пользователь отклонил permission на уведомления, When он включает напоминание у задачи, Then показывается объяснение и путь в настройки системы.
4. Given задача отмечена выполненной или удалена до срабатывания, When время напоминания наступает, Then уведомление не показывается.
5. Given повторяющаяся задача, When срабатывает напоминание и создаётся/сдвигается следующий экземпляр по текущим правилам повтора, Then напоминание планируется на следующий срок.
6. Given уведомление показано, When пользователь нажимает на него, Then открывается приложение на этой задаче (или список с фокусом на задаче).
7. Given задача с напоминанием, When пользователь редактирует срок, Then старое напоминание отменяется, новое планируется.

## Бизнес-правила

- Напоминание по умолчанию: в момент `dueTime` (или начала интервала); для all-day — **09:00** локального времени дня задачи (значение по умолчанию, настраиваемо позже).
- В v1: одно напоминание на задачу (не цепочка «за 1 день / за 1 час»), если стейкхолдер не расширит scope.
- Покупки в v1 **вне** напоминаний (отдельное решение).
- Без сети напоминания работают (локальные alarms/notifications).

## Вне scope

- Гео-напоминания, email-напоминания
- Умные «предложи перенести»
- Напоминания для пунктов покупок
- Обязательный exact-alarm без объяснения производителей OEM (документировать ограничения Xiaomi/Huawei в ТЗ)

## Зависимости

- B-002 (сроки), B-003 (повторы)
- Разрешение `POST_NOTIFICATIONS` (Android 13+)

## Открытые вопросы

1. Нужен ли отдельный переключатель «напоминание вкл/выкл» на задаче или «есть срок ⇒ всегда напоминать»?
2. Смещение по умолчанию для all-day — 09:00 ок?
3. Нужны ли пресеты «за 15 мин / за 1 час» уже в первой версии?
