# Рыночный анализ: органайзеры и планировщики задач

- Дата: 2026-07-27
- Автор: BA
- Продукт: Task Tracker (android-task-tracker)
- Цель анализа: сравнить рыночные решения органайзеров/планировщиков, зафиксировать плюсы и минусы, выявить gaps для развития нашего Android-приложения

> **Метод.** Синтез публичных обзоров и сравнений 2025–2026 (Zapier, RateTheTool, DroidLore, vc.ru, DTF, материалы вендоров). Это **вторичный** анализ, не полевое UX-тестирование. Цены и лимиты тарифов могут меняться — сверять перед решениями о монетизации.

---

## Сегмент и аудитория

- **Категория:** personal task managers / to-do / органайзеры (не enterprise PM вроде Jira/Asana как основной фокус)
- **Целевые пользователи:** частные лица и малые команды; студенты; фрилансеры; семьи (быт + покупки)
- **Jobs-to-be-done:**
  - быстро зафиксировать обязательство («выгрузить из головы»)
  - спланировать день / неделю
  - не пропустить дедлайн и повторяющиеся дела
  - иногда — совместить задачи с календарём, привычками, списками покупок
- **Гео / платформы:** глобальный рынок + специфика РФ (оплата, RuStore, реестр ПО); наш продукт сейчас — **Android, локальное хранение**

## Плюсы и минусы по приложениям

### Todoist

**Плюсы**
- Эталонный ввод на естественном языке («каждый понедельник в 9 p1»)
- Проекты, секции, метки, мощные фильтры
- Стабильный кроссплатформенный sync и десятки интеграций
- Karma / геймификация поддерживает привычку пользоваться
- AI-помощь (разбор задач) на платных планах

**Минусы**
- Жёсткий free: мало проектов; напоминания и часть организации — в Pro
- Календарь и привычки слабее, чем у TickTick
- Для РФ: оплата зарубежной картой / посредники
- Не заменяет полноценный project management

### TickTick

**Плюсы**
- Задачи + календарь + привычки + Pomodoro + kanban в одном продукте
- Один из лучших price/value на рынке Premium
- Щедрый free относительно Todoist
- Удобен тем, кто мыслит «временем на календаре», а не только списком

**Минусы**
- Плотность фич → когнитивная перегрузка на старте
- Меньше нативных интеграций
- Дизайн менее «чистый», чем у Todoist / To Do
- Командная работа вторична

### Microsoft To Do

**Плюсы**
- Полностью бесплатное ядро без апсейла «напоминания за деньги»
- «Мой день» — сильный анти-оверлоад паттерн
- Flag email → задача (Outlook), связка с Planner
- Минималистичный спокойный UI

**Минусы**
- Плоские списки, слабые фильтры/метки/иерархия
- Нет привычек, Pomodoro, kanban «из коробки»
- NLP и продвинутые повторы слабее Todoist
- Нужен Microsoft-аккаунт; без экосистемы MS ценность ниже

### Google Tasks

**Плюсы**
- Встроен в Gmail / Google Calendar — нулевой friction
- Бесплатно, просто

**Минусы**
- Минимум организации (почти «заметки со сроком»)
- Слаб как самостоятельный органайзер
- Привязка к Google

### Any.do

**Плюсы**
- Plan My Day / ритуал планирования
- Быстрый захват, голос, удобный mobile-first UX
- Shared lists для семьи

**Минусы**
- Быстро упирается в потолок для сложных систем
- Важные фичи уезжают в Premium
- Меньше «глубины», чем у Todoist/TickTick

### Notion (как task manager)

**Плюсы**
- Задачи + документы + базы в одном workspace
- Гибкие представления (таблица, доска, календарь)
- Силён для команд с общей базой знаний

**Минусы**
- Долгий setup; легко «строить систему вместо работы»
- Mobile и скорость захвата хуже dedicated to-do
- Полноценный AI — на дорогих планах

### SingularityApp

**Плюсы**
- Глубокая вложенность, kanban/Gantt, привычки, Pomodoro
- Оплата в ₽, RuStore, реестр ПО, VK/Яндекс-логин
- Telegram / голос для захвата

**Минусы**
- Free часто режет sync / устройства
- Интерфейс требует обучения
- Обзоры вендора предвзяты — сверять независимыми отзывами

### ЛидерТаск

**Плюсы**
- Сильная иерархия и офлайн с последующей sync
- Захват через email/Telegram; ориентация на РФ/бизнес
- Коробочные сценарии для организаций

**Минусы**
- UX воспринимается тяжелее современных конкурентов
- Для «просто список дел» — избыточен
- Mobile vs desktop опыт неоднороден (по отзывам обзоров)

### Task Tracker (наш продукт) — текущее положение

**Плюсы (факт по коду)**
- Полный офлайн, без обязательного аккаунта и облака
- Задачи: приоритет, дата/время (в т.ч. интервал), заметки, гибкие повторы (вкл. свои дни недели)
- Подзадачи (включаемые в настройках)
- Список покупок с категориями — бытовой органайзер «рядом» с задачами
- Drag-and-drop, фильтры активных/готовых

**Минусы / пробелы vs рынок**
- Только Android; нет web/desktop/iOS
- Нет облачной синхронизации и бэкапа между устройствами
- Нет напоминаний / push (критичный must рынка)
- Нет проектов/списков/меток/календаря/привычек/Pomodoro
- Нет командной работы и интеграций
- Нет NLP-быстрого ввода

## Gaps и возможности (для Task Tracker)

### Must (критично для паритета «личного планировщика»)
- Напоминания / уведомления по сроку и времени
- Организация: хотя бы списки или проекты (иначе масштаб >30–50 задач болезненен)
- Надёжный локальный бэкап / экспорт (раз нет облака — пользователь боится потери данных)

### Should (ожидание рынка / дифференциатор)
- Вид «Сегодня / Мой день» (паттерн MS To Do / Any.do) — снижает оверлоад
- Усиление связки **задачи + покупки** как явного позиционирования «домашний органайзер»
- Календарный/дневной таймлайн для задач со временем
- Виджеты Android, быстрый захват с шторки/шортката

### Could (позже)
- Привычки + streak
- Pomodoro
- Метки и умные фильтры
- Опциональный sync (с прозрачной политикой данных)
- NLP-ввод дат
- Шаринг семейного списка покупок

## Позиционирование

- **Что копировать:** ритуал «Мой день»; надёжные напоминания; простая иерархия списков; гибкие повторы (у нас уже сильны — сохранить и не усложнить UX).
- **Чего избегать:** feature-bloat TickTick/Notion на старте; обязательный аккаунт; paywall на базовых напоминаниях (боль Todoist free).
- **Уникальное предложение (гипотеза):** *локальный Android-органайзер без аккаунта: задачи с нормальным планированием + список покупок в одном месте, приватность и офлайн как преимущество, а не «недоделка».*

---

## Рекомендации для требований

1. Зафиксировать epic **«Напоминания»** и **«Списки/проекты»** как Must перед расширением «комбайна».
2. Явно описать ценность **покупок** в PRD (сейчас это редкий дифференциатор vs чистых to-do).
3. Сформулировать NFR: офлайн-first, работа без аккаунта, политика бэкапа.
4. Для РФ-аудитории не строить go-to-market на западных подписках — наш путь ближе к «простому локальному» + опционально RuStore, чем к Todoist-клону.
5. Следующий артефакт BA: черновик `docs/ba/requirements.md` на основе Must/Should выше (по запросу).
